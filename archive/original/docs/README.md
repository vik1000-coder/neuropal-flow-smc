# Documentation

Documentation is split by status so that current conclusions do not get mixed
with the history of how the project arrived there.

- [`current/`](current/README.md): the recommended reading path for the active
  conditional-flow and progressive-bridge-SMC analysis.
- [`history/`](history/README.md): superseded indexes, earlier method families,
  and useful developmental records.

Large result-specific reports remain beside the artifacts they describe under
[`../results/`](../results/README.md). This avoids breaking relative links,
manifests, and checksum-bound result bundles.
