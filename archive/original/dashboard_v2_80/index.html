How to read the uncertainty

Interval for the mean

The shaded pointwise interval resamples 20 historical traces. The trained seed-1701 generator stays fixed.

Variation between traces

Individual lines and dots expose model-effect heterogeneity. Pseudo-pairing and donor imputation limit an animal-level interpretation.

Sampler support

Validity, effective sample size, source gap, and repaired-root ancestry help diagnose finite-particle behavior. They cannot correct model or data errors.

Generator sensitivity

The main atlas uses one seed selected by held-out predictive score. Reference checks retain the stronger two-seed result as a separate sensitivity view.
