# Conditional flow model report

This directory contains the LaTeX source and cited bibliography for the 1 September 2026 scientific synthesis of the conditional model-development program.

- `main.tex`: report source
- `references.bib`: external primary references
- `figures/`: frozen figures copied from the corrected distribution-structure analysis
- `build/`: LaTeX build products

The report deliberately separates the corrected 17-worm comparison from older development benchmarks whose cohorts or evaluation banks differ. The revised version includes the complete 16-candidate density/energy screen, the separate denoising-score objective screen, and an explicit decomposition of the variability these models can learn.
