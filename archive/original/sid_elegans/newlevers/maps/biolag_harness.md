# CLUSTER: biolag_harness

## conventions
CENTRAL DATA SHAPES. (1) `X_list`: Python list of per-worm arrays, each `[T_w, N]` float64, columns in `neuron_names` order (same N across worms). T_w varies per worm; there is NO cross-worm concatenation before fitting (windows built per worm to avoid leakage, then pooled inside the estimator). Missing neurons = all-NaN columns; sporadic dropout frames = scattered NaNs. `names` are UPPERCASE, already D/V- and L/R-collapsed to CLASS level by combined_data.load_combined (so a "neuron" here is effectively a class). Standardization is GLOBAL: each neuron centered by its grand mean, then ALL divided by ONE global scalar SD (combined_data.py:106-109) — NOT per-neuron z-scoring (that is deliberately avoided; per-neuron scaling destroys the variance-magnitude signal the gain channel reads). fps=4.0 everywhere.

(2) ORIENTATION IS UNIVERSAL `[post, pre] = [target, source]`: every adjacency and every estimator matrix is `A[j, i] != 0` meaning edge source i -> target j. This holds for Cook, monoamine, neuropeptide, Leifer references AND all estimator channels. The lagres metric (lagres/metric.py) and evaluate._offdiag NEVER transpose. New code must keep this; do not transpose.

(3) ESTIMATOR OUTPUT: fit_distributional_connectome returns a ConnectomeResult whose `.matrices` is a dict with keys ("mean","gain","tail_hi","tail_lo"), each an `[N,N]` float64 `[post,pre]` array. The DIAGONAL of every channel is FORCIBLY ZEROED (self-coupling discarded) — the self/diagonal value is computed then overwritten with 0.0 and is unrecoverable from the return value. The biolag scripts derive a "tail" channel as `abs(tail_hi)+abs(tail_lo)`. Scoring always uses `abs(matrix)` off-diagonal vs `(ref>0)` binary.

(4) LAG GRID: `C.LAG_FRAMES = [1,2,3,5,8,10,15,20,30,40]` (0.25..10 s at 4 Hz); analyses scan this list, one estimator fit PER lag. BANDS: `metric.BANDS` is computed AT IMPORT from `C.bands()` (fast=(0.25,1.0)s, slow=(2.5,10.0)s under the active two-band scheme). expected_band is 'slow' for monoamine/neuropeptide, 'fast' for gap/chemical. band_concordance(z, expected_band) = mean z in expected band minus mean z in the complementary band; its complementary logic ONLY handles fast<->slow.

(5) REFERENCES: `references.build_registry(neuron_names, min_specific_edges=10)` returns a list of `Reference` dataclasses, each carrying `.name` (e.g. "neuropeptide:all"), `.adjacency` ([N,N] float binary [post,pre]), `.expected_band`, `.expected_channel`, `.n_edges`. The harness filters this list to a hardcoded REFS subset. Any object with `.name/.adjacency/.expected_band` flows through the whole metric machinery.

(6) RUN-BLOCK STRUCTURE (the reusable statistical skeleton, run_comprehensive.py:100 / run_acmma_phase2.py:91): a `run_block(X, names, refs, mask, tag, rng)` computes (a) OBSERVED per-(channel,ref) AUROC-vs-lag curves via `curves()`/`acmma_curves()`; (b) N_SURR circular-shift SURROGATE curve sets (circshift), from which per-lag null mean mu0 and std sd0 are formed; (c) z = (curve-mu0)/sd0, then band_concordance -> BC per channel, dBC = BC_gain - BC_mean; (d) surrogate p-values p_dBC/p_BCgain = (#surr >= obs +1)/(n+1); (e) N_BOOT WORM-bootstrap (resample worms with replacement, refit, rescore, z against the SAME mu0/sd0) -> percentile CI via stat(); (f) a source-variance BC control that must return ~0. A full run does this block TWICE per data config: PRIMARY then GLOBAL-MODE-removed. RNG is a single np.random.default_rng(0) threaded through surrogates+bootstraps.

(7) ENV-VAR PARAMETRIZATION (compute-gentle): run_comprehensive uses COMP_NSURR/COMP_NBOOT (default 25), COMP_THROTTLE (0.6s sleep between worm-sets), COMP_CONFIGS. run_acmma_phase2 uses ACMMA_NSURR/ACMMA_NBOOT (25), ACMMA_THROTTLE (0.4), ACMMA_RIDGE (0.01 — do NOT default to 3.0, it is an over-regularization artifact), ACMMA_DATA. Also honors OPENBLAS_NUM_THREADS. New run scripts should mirror this NSURR/NBOOT/THROTTLE/RIDGE env convention.

(8) EVAL MASK: `mt.eval_mask(N)` returns a boolean `~eye(N)` off-diagonal mask; optional `both_present=bool[N]` drops pairs touching absent neurons (avoids fake negatives). corr_score treats every non-positive ref entry as a true negative, so restricting the mask matters when a reference only confirms a subset of edges (e.g. Leifer).

## key_functions
### fit_distributional_connectome  (estimator.py)
- sig: `fit_distributional_connectome(X_list, neuron_names, lag:int, target_mode:str='next', ridge:float=1e-2, heldout_frac:float=0.2, source_tau:float|None=None, fps:float=4.0, seed:int=0, sigma_frac:float=0.0) -> ConnectomeResult`
- returns: ConnectomeResult dataclass (estimator.py:53): .lag:int, .neuron_names:list, .matrices:dict{'mean','gain','tail_hi','tail_lo' -> [N,N] float64 [post,pre]}, .invalid_fraction:np.ndarray[N] (per-target invalid-variance fraction), .heldout_nll:np.ndarray[N] (per-target held-out mean NLL, NaN if fit skipped). DIAGONAL OF EVERY CHANNEL ZEROED.
- purpose: THE core closed-form SID estimator. Per target j fits sid_neuromod QuadraticScoreMatcher of Y_j(t+lag) on psi=[1, centered sources at t]; reads out d E[Y]/dx_i (mean), d logVar[Y]/dx_i (gain), tail derivatives at the mean history. sigma_frac=0 => Hyvarinen SM; sigma_frac>0 => denoising SM at sigma=sigma_frac*sd(Y) with sigma^2 subtracted at readout. source_tau (in FRAMES) replaces instantaneous sources with a causal exp filter (slow drive).
- gotchas: DIAGONAL/self value is computed as rd[channel][1+j] then OVERWRITTEN with 0.0 at lines 175-177 and cannot be recovered from the return (blocks hook 3 without editing here). Targets with <3*N pooled valid rows are silently left as all-zero rows (line 149). Source NaNs -> 0 (the standardized mean); rows with NaN target dropped. Held-out split is CONTIGUOUS (line 157 ntr=int((1-heldout_frac)*len(Y))) not random. q_hi/q_lo are the 0.90/0.10 quantiles of the TRAIN target. Readout is at the pooled-mean history (sources centered, line 153). Not parallelized; loops N targets in Python.

### fit_acmma_connectome  (acmma.py)
- sig: `fit_acmma_connectome(X_list, names, lag, ridge=1.0, min_triple=8, shrink=0.05, eta2_min=1e-6, var_min=1e-6, q_hi=0.90, q_lo=0.10, sigma_frac=0.0) -> (mats, diag)`
- returns: tuple (mats, diag). mats: dict{'mean','gain','tail_hi','tail_lo' -> [N,N] float64 [post,pre]}, diagonals zeroed, non-finite readout entries set to 0. diag: dict{'clipped_eigen_mass_median','clipped_eigen_mass_max','masked_gain_frac_median'} floats.
- purpose: Available-Case Multivariate Moment Assembly variant of the SID gain estimator: uses ALL worms with zero imputation by assembling each Gram entry available-case (only over rows where the needed neurons co-occur, normalized by that entry's own co-observation count). Byte-identical readout to estimator.py. Callers pass ridge=0.01 (RIDGE env), min_triple=2000, shrink=0.05.
- gotchas: Returns a 2-TUPLE not a ConnectomeResult (unpack `m,_ = fit_acmma_connectome(...)`). Signature default ridge=1.0 and min_triple=8 are NOT what the harness uses (it passes 0.01 and 2000). HARD-MASKS thin-triple gain entries (Nik<min_triple) to 0.0 (acmma.py:98-100) — with min_triple=2000 this zeroes many edges on small worm sets. Self/diagonal gain value is d_gain[1+j] then zeroed at lines 140-141 (same limitation as estimator for hook 3). PSD repair (Ledoit-Wolf shrink toward scaled identity + eigen-clip) inside _nearest_psd (acmma.py:44) — the existing shrinkage surface for hook 7.

### band_concordance  (metric.py)
- sig: `band_concordance(z, expected_band) -> float`
- returns: float scalar (or np.nan if either band has no finite z). BC = nanmean(z in expected band) - nanmean(z in complementary band).
- purpose: Turns a null-referenced z(lag) curve into one biologically-scored number: positive => above-null correspondence concentrated in the expected (slow for modulatory, fast for structural) band.
- gotchas: Reads module-global metric.BANDS which is frozen AT IMPORT from C.bands(); to use four-band you must set C.ACTIVE_BANDS='four' BEFORE importing metric. Complementary-band logic (line 47) ONLY understands 'fast'<->'slow'; four-band names break it. Expects z indexed over the full C.LAG_FRAMES.

### sid_curves  (metric.py)
- sig: `sid_curves(X_list, names, refs, mask) -> dict`
- returns: dict {ref.name -> {'mean':arr,'gain':arr,'tail':arr}} each arr an np.ndarray of len(LAGS) float AUROC values.
- purpose: Builds the AUROC-vs-lag curves for SID mean/gain/tail channels over all refs; the observed-curve builder inside a run block. run_comprehensive uses a richer local `curves()` (adds baselines + SID_dsm) and run_acmma uses `acmma_curves()`; all three share the same shape contract.
- gotchas: Re-fits the estimator ONCE PER LAG (10 fits) with ridge=1e-2, target_mode='next'. tail channel = abs(tail_hi)+abs(tail_lo). This is the function a new scoring axis (hook 5 predictive_likelihood) must PARALLEL — swap mt.corr_score for model.nll and drop the band machinery.

### corr_score  (metric.py)
- sig: `corr_score(E, R, mask, metric='auroc') -> float`
- returns: float AUROC/AUPRC/Spearman, or np.nan if degenerate (all-pos/all-neg ref, empty mask).
- purpose: The one-lag scoring primitive every curve builder calls: scores abs(E)[mask] against (R>0)[mask]. metric in {'auroc','auprc','spearman'}.
- gotchas: Uses abs(E) and binarizes R at >0, so ALL zero/absent ref entries are negatives (fake-negative risk for partial references like Leifer -> restrict mask). Drops non-finite. This is the swap-point to replace AUROC with predictive likelihood (hook 5).

### eval_mask  (metric.py)
- sig: `eval_mask(N, both_present=None, symmetric_ref=False) -> np.ndarray[bool]`
- returns: [N,N] bool off-diagonal mask; both_present=bool[N] additionally ANDs np.outer(p,p) to drop pairs touching absent neurons.
- purpose: Off-diagonal evaluation mask shared by all scoring. Harness calls eval_mask(len(names)) (full off-diagonal).
- gotchas: symmetric_ref is accepted but currently unused inside; for undirected refs you symmetrize E upstream. Use both_present to confine Leifer scoring to atlas-supported neurons (hook 1).

### build_registry  (references.py)
- sig: `build_registry(neuron_names, min_specific_edges:int=10, verbose:bool=True) -> list[Reference]`
- returns: list of Reference dataclass (references.py:23): .name, .family, .level('structural'|'class'|'specific'), .adjacency [N,N] float binary [post,pre], .n_edges:int, .expected_band, .expected_channel.
- purpose: The single place references are constructed (structural gap+chem, monoamine class+specific, neuropeptide class+specific). This is where hook 1 (functional_target) adds a 'functional:leifer' Reference.
- gotchas: Specific refs with <min_specific_edges edges are DROPPED. adjacency built via ground_truth.build_monoamine_layer which collapses bilateral L/R to class. To add Leifer you must also register an expected_band/expected_channel (config.FAMILIES has no 'functional' family — either add one or reuse). Harness then filters build_registry output to a hardcoded REFS list (run_comprehensive.py:47, run_acmma_phase2.py:41) so a new ref name must be added THERE too.

### circshift  (metric.py)
- sig: `circshift(X_list, rng) -> list`
- returns: new list of [T,N] arrays; each neuron column independently circularly rolled by a random offset in [1,T).
- purpose: The surrogate-null generator: destroys cross-neuron lag alignment (and the shared global mode) while preserving each neuron's marginal/autocorrelation. Drives mu0/sd0 in every run block.
- gotchas: Per-column independent roll (offset drawn per neuron). Consumes the shared rng, so surrogate draws are entangled with bootstrap draws in call order. Note this null DESTROYS the global brain-state mode — which is exactly why the global-mode-preserving control block exists, and why hook 2 wants to CONDITION on the mode instead.

### remove_global_mode  (metric.py)
- sig: `remove_global_mode(X_list, n_pc=1) -> list`
- returns: list of [T,N] float arrays = residuals after projecting out the top-n_pc SVD components per worm; NaNs replaced by 0 (nan_to_num) BEFORE SVD so output is dense (no NaN).
- purpose: The confound control used by run_comprehensive: fit a run block on residuals to show the peptidergic effect survives removing the shared global brain-state mode.
- gotchas: Mean-centers per worm then subtracts rank-n_pc reconstruction; DENSIFIES NaNs to 0 (loses missingness). For hook 2 you do NOT want to remove this mode — you want the removed component itself: recover the global signal as U[:,:n_pc]*S[:n_pc]@Vt[:n_pc] (or the PC1 score U[:,0]*S[0]) as the modulator variable.

### remove_global_mode_nan  (run_acmma_phase2.py)
- sig: `remove_global_mode_nan(X_list, n_pc=1) -> list`
- returns: list of [T,N] arrays with NaN missingness PRESERVED; per-column global-signal regression residuals (col = col - beta*g on present rows), NaN where originally absent.
- purpose: NaN-aware global-signal regression for the available-case ACMMA pipeline (respects the missingness mask). n_pc argument is accepted but ignored (always uses the mean global signal).
- gotchas: The global signal g = nanmean over present neurons per frame (line 47) is EXACTLY the per-worm modulator timeseries hook 2 needs — extract g (before residualizing) and feed it as a conditioning column. Columns with <5 present frames are left unregressed. Only defined inside this run script (not in metric.py).

### source_variance_curve  (metric.py)
- sig: `source_variance_curve(X_list, names, ref, mask) -> np.ndarray`
- returns: np.ndarray len(LAGS), constant across lags = AUROC of a source-variance-ranked matrix vs ref.
- purpose: Trivial positive control (must give BC~0): ranks edges purely by source-neuron activity variance, lag-flat by construction. Also the ready-made per-neuron variance vector for building variance-MATCHED controls (hooks 2,3,5).
- gotchas: Builds V = var over concatenated nan_to_num(x) (NaN->0 lowers variance for sparsely-observed neurons). Cmat[j,i]=V[i] (source variance broadcast), diagonal zeroed.

### QuadraticScoreMatcher  (quadratic_score.py)
- sig: `QuadraticScoreMatcher(sigma=0.0, ridge=1e-6, eta2_min=1e-6, var_min=1e-6, seed=0); .fit(Y, Psi, sigma=None, ridge=None)->FitResult; .nll(Y,Psi)->float; .logpdf(Y,Psi)->[T]; .predict_params(Psi)->(eta1,eta2,mu,var)`
- returns: fit -> FitResult(theta[2P], P, sigma, ridge, A[2P,2P], xi[T,2P], invalid_variance_fraction, ...). .theta1/.theta2 properties slice theta. nll -> mean held-out negative log-likelihood float.
- purpose: The linear closed-form conditional-density core the SID estimator wraps. Psi is ANY [T,P] feature matrix with col0=intercept — it is a linear probe on whatever features you supply (the hook point for frozen_features #6 and predictive_likelihood #5).
- gotchas: Agnostic to feature meaning: swap the source block of Psi for frozen-trunk features and edge readouts become feature-space (need a Jacobian back to neurons). nll/logpdf give per-model held-out likelihood directly (hook 5). eta2 clamped at prediction only. sigma>0 draws noise (seeded) — nondeterministic across seeds.

### sigma_ledger  (quadratic_score.py)
- sig: `sigma_ledger(Y, Psi, ridge=1e-6, sigma_fracs=(0.0,0.25,0.5,1.0), seed=0) -> list[dict]`
- returns: list of dict{'sigma_frac','sigma','mean_at_center','var_at_center'} one per sigma.
- purpose: READY-MADE geometric denoising-sigma ladder for ONE target: fits at each sigma and returns the sigma^2-corrected readout at the mean history (a cross-sigma consistency diagnostic). The natural primitive to build noise_ladder (hook 8) on top of.
- gotchas: Per-target scalar readouts only (mean/var at center), not full [N,N] matrices — to get ladder-coupled edge matrices you must generalize this to return the source-derivative readouts, or loop fit_distributional_connectome over sigma_fracs and aggregate the gain channel.

### load_leifer  (ground_truth.py)
- sig: `load_leifer(neuron_names, alpha:float=0.05) -> dict|None`
- returns: dict{'q':[N,N] reindexed q-values [post,pre], 'positive':[N,N] float binary (q<alpha)} OR None if wormneuroatlas unavailable / load fails.
- purpose: Loads the Randi/Leifer FUNCTIONAL connectome via wormneuroatlas — directly the ground truth for hook 1 (functional_target). 'positive' is [post,pre], ready to be a Reference.adjacency.
- gotchas: Returns None (not raise) if wormneuroatlas is not installed or download fails — callers must guard. q reindexed with nan->1.0 (absent = non-significant). q_eq (confirmed-negative) is fetched but not returned; to avoid fake negatives you should build a mask of confirmed edges (positives OR confirmed negatives) rather than scoring all zeros as negatives. First call may download atlas data (network + disk).

### load_combined  (combined_data.py)
- sig: `load_combined(coverage_frac:float=0.6, complete_case:bool=True, min_worms_per_neuron:int=6, signal:str='raw', verbose:bool=True) -> (X_list, neuron_names, fps)`
- returns: (X_list list of [T,N] float64 globally-standardized, neuron_names list[str] UPPERCASE class-level, fps=4.0). complete_case=True => ~6 worms x 80 neurons no NaN; complete_case=False => ~28 worms x 84 neurons with NaN columns.
- purpose: The canonical data loader for the biolag run scripts. signal='deconv' applies OASIS calcium deconvolution. This is what a new run script calls first.
- gotchas: GLOBAL standardization (one SD for all neurons) — do not re-z-score per neuron downstream. complete_case=False leaves all-NaN columns for neurons absent in a worm; ACMMA handles them natively, estimator.py mean-imputes to 0, run_comprehensive donor-imputes first. signal must be 'raw' or 'deconv'. Loads from the SBTG repo dir; needs PYTHONPATH=.:SBTG.

### impute_random_donor  (impute.py)
- sig: `impute_random_donor(X_list, seed:int=0) -> (out_list, n_imputed:int)`
- returns: (copy of X_list with each all-NaN neuron column filled by a random donor worm's real trace resized to recipient length, count of imputed columns).
- purpose: Densifies the 28-worm set for the multivariate estimator without the flat-trace confound (run_comprehensive '28w_imputed' config). Donor traces carry realistic variance but are decoupled -> imputed edges dilute toward chance.
- gotchas: Only fills WHOLE missing columns (all-NaN); leaves sporadic within-trace NaNs. Neurons present in no other worm stay all-NaN. Returns a COPY (X_list not mutated). np.resize tiles/truncates the donor trace (introduces a tiling seam).

### significance.perm_p / boot_diff / auroc  (significance.py)
- sig: `auroc(M, gt)->float; perm_p(M, gt, n=2000, seed=0)->(obs, pval); boot_diff(Ma, Mb, gt, n=2000, seed=0)->(mean, lo, hi)`
- returns: auroc: float; perm_p: (obs AUROC, permutation p that AUROC>chance); boot_diff: (mean, 2.5%, 97.5%) of AUROC(Ma)-AUROC(Mb) resampling the shared off-diagonal edge set.
- purpose: Edge-level (NOT worm-level) significance for single-lag connectome-recovery comparisons; uses evaluate._offdiag. Template for how to attach a permutation p and a paired bootstrap CI to any two matrices vs a ground truth.
- gotchas: Bootstrap is over EDGES (off-diagonal entries) not worms — different resampling unit from the run-block worm-bootstrap. _vecs uses abs(offdiag(M)) vs (offdiag(gt)>0). significance.main() APPENDS to output/REPORT.md (side effect: reads then rewrites the file) — do not call main() from a new script unintentionally.

- **7. hierarchical_shrinkage (empirical-Bayes/James-Stein toward a class prior)**: ACMMA is the natural host — it already does Ledoit-Wolf shrinkage toward a scaled identity in _nearest_psd (acmma.py:44, `shrink` param, SHRINK=0.05 at run_acmma_phase2.py:40) and hard-masks thin triples (acmma.py:98-100). Two concrete points: (A) POST-fit James-Stein — after fit_acmma_connectome returns mats (acmma.py:145), shrink each per-edge value toward its class-mean edge (reuse hook 4's class map) with a JS factor from the per-edge sampling variance (approx via Nik co-observation counts, acmma.py:82). (B) MOMENT-level — shrink the assembled per-edge moment estimates s1,s2 (acmma.py:91) toward a class/population prior BEFORE the solve at acmma.py:123; more principled but requires editing inside the target loop and re-deriving the effective ridge. The existing clipped/masked diagnostics (acmma.py:142-144) are the reporting surface to extend with a shrinkage-intensity diagnostic.
- **8. noise_ladder (couple a geometric denoising-sigma ladder into one estimator)**: sigma_frac is currently a SCALAR per fit (estimator.py:132, acmma.py:56); run_comprehensive already runs sigma_frac=0.0 (SID_hyv) and 0.5 (SID_dsm) as SEPARATE fits at run_comprehensive.py:58-59. The ready-made ladder primitive is sid_neuromod...sigma_ledger (quadratic_score.py:216) which loops sigma_fracs=(0,0.25,0.5,1.0) for one target. To COUPLE the ladder: wrap run_comprehensive.est_matrices (run_comprehensive.py:56) to loop a geometric sigma_frac grid, fit fit_distributional_connectome at each, and aggregate the gain channel across the ladder (weighted mean or consistency-gated combination). Because the denoising readout already subtracts sigma^2 (estimator.py:160 & _center_readouts line 108 v=v_eff-sigma^2; acmma.py:127), the per-sigma gain matrices are on a common scale, so ladder aggregation is a variance-reduction step, not a rescaling. Alternatively extend fit_distributional_connectome to accept a sigma_fracs list and return a combined matrices dict; the run_block/scoring layer above is then unchanged.

## resource_notes
MEMORY: no OOM risk on 16GB. All linear-algebra objects are tiny: the estimator/ACMMA Gram matrix A is [2P,2P] with P=N+1 (~85), i.e. <=170x170 (~230KB); reference/estimator matrices are [N,N] float64 (~55KB at N=84). The only sizeable transient is the pooled design U=[T_pooled, 2P] inside QuadraticScoreMatcher.fit — T_pooled across 28 worms is ~1e4-5e4 rows, so U ~ 5e4*170*8B ~ 68MB, allocated and freed per target; peak stays well under 1GB even with surrogate/bootstrap loops (each run_block holds only small curve dicts: CHANNELS x refs x len(LAGS) floats). impute_random_donor densifies NaN columns (more nonzero data per fit on the 28w config) but does not change array shapes.

COMPUTE (the real cost, CPU-bound, no GPU): fit_distributional_connectome loops N Python-level target fits, each forming U'U (~T*(2P)^2 flops). One curves() call = 10 lags x (2 SID fits + 2 baselines for run_comprehensive, or 2 SID for sid_curves). A full run_block does 1 observed + N_SURR surrogate + N_BOOT bootstrap curve evaluations, and main() runs it TWICE per config (primary + global-mode) across CONFIGS. With defaults NSURR=NBOOT=25 and 2 configs that is ~2*2*(1+25+25)=~204 full curve evaluations, each 10 lags x N target-fits x up to 2 estimators — hours-scale on a laptop. The THROTTLE env vars (COMP_THROTTLE=0.6s, ACMMA_THROTTLE=0.4s sleeps between worm-sets) exist specifically to keep a shared machine responsive; honor OPENBLAS_NUM_THREADS to cap BLAS threads. New scripts should reuse NSURR/NBOOT/THROTTLE/RIDGE env gating and start with small NSURR/NBOOT for smoke tests.

MPS/torch: the closed-form estimators (estimator.py, acmma.py) and all baselines are pure NumPy/SciPy (no torch, no MPS). The only torch path is the MDN trunk fit_mdn (lagres/effects.py:123, needed for hook 6 frozen_features) which defaults to device='cpu'; the nets are small (hidden=128, layers=2, k=3) so even if moved to MPS memory is trivial, but MPS gives little speedup at this size and adds float32/float64 friction with the NumPy readout path. NETWORK/DISK: hook 1's wormneuroatlas (load_leifer, ground_truth.py:133) may download atlas data on first use and returns None if the package is absent — guard for it. combined_data with signal='deconv' runs OASIS deconvolution per worm (sid_elegans.deconv), a modest one-time CPU cost at load."
