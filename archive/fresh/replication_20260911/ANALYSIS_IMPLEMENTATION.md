# Analysis implementation details fixed before response evaluation

Written 11 September 2026, during initial flow fitting, before opening any new response matrix or computing atlas scores. This supplements the frozen protocol without altering its primary fits, sampling or comparisons.

- Independent predictive bank: 16 evenly spaced eligible histories per held-out recording and observed stimulus stratum, shared across methods and seeds; 32 generated paths at six horizons. Ridge uses a fixed alpha of 10 and the existing compact causal multiscale features; its full residual covariance and persistence covariance use training recordings only. These are fixed diagnostic comparators, not tuned winners.
- Reference lag-maximum sensitivity: 2,000 within-source label permutations, identical permutation across lags; state-average/onset-minus-baseline endpoint mean/W1, four Cook/Randi references, fixed strong-support source set. Holm correction over the 16 registered cells per cohort. This null assumes within-source target-label exchangeability and tests reference correspondence, not a physical delay. It supplements the exact joint recording sign-flip effect/lag test.
- Zero-query negative control: both cohorts, fold 0's first held-out recording, baseline/onset event 0, nominal lags 1/4, N64/N512, three independent MC seeds. Both arms request exactly the same clamp center. The raw contrast has exact target zero; a noisy achieved gap must not be used to fabricate a derivative. Report raw zero-query MSE and its particle dependence.
- Derivative reports retain both normalization by requested separation (a derivative with respect to softened clamp location) and by achieved displacement (the historical secant interpretation). Both remain model-relative. Fixed bandwidth, finite-memory generator and changing repair boundary limit their interpretation.
- Exact max-T is streamed over every registered strong-support effect and lag-contrast feature, sharing each recording's sign across the entire family. Source-block bootstrap uncertainty for reference AUROC is conditional on the matrices and external labels. Neither calculation treats seeds or particles as additional animals.
- A boundary-best training run triggers separate fresh 200-epoch/patience-20 fitting and full-grid resampling. The original primary archives are retained. For a labeled extended-training ensemble, only triggered checkpoints are replaced; untriggered primary checkpoints remain, and the replacement ledger is explicit. Extension decisions use validation traces only and are executed before reference evaluation.
- Frozen oracle gates were N1024 mean bias RMSE below .03 and N1024 run RMSE below N32, at nominal lags 0/1/4/16. Three intermediate particle levels do not require monotone errors in every individual cell.

The W1 channel is an unsigned distributional distance, not a signed derivative. Its lag correspondence is separately labeled. The new joint inference family uses baseline and onset-minus-baseline channels; the older E29 active-minus-baseline family is not claimed to be an identical rerun. Active-minus-baseline matrices and descriptive profiles are also retained.

Large direct N16384 diagnostic reference banks use sampling seeds offset by 104729 from the matched comparison MC identifiers, so N4096 paths are not nested inside the reference. Each N16384 self-comparison uses the other two independent reference runs (leave-one-out); it is not compared to a reference mean containing itself. All effective seeds are recorded.
