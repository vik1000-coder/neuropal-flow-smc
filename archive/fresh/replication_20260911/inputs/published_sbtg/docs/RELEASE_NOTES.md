# Release notes

This release combines the reproducible pipeline, portable reference inputs, manuscript artifacts, and validated sensitivity analyses.

Material updates include:

- portable production-lineage code and prepared inputs for lag-profile and phase-duration sensitivity fits;
- recording-held-out residual diagnostics and structured-innovation simulations;
- lag-profile resampling, duration matching, method agreement, and partial-observation analyses;
- companion-matrix stabilization for the VAR(2) generator;
- canonical perturbational-response labels;
- pickle-free NPZ artifacts with JSON hyperparameters;
- explicit manuscript hybrid-lineage documentation;
- corrected functional-atlas metrics and removal of unsupported sub-frame peak interpretations;
- privacy, schema, checksum, compilation, and numerical validation tooling.
