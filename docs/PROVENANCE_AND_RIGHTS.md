# Provenance and attribution

This archive was assembled from the author's authorized local research workspace
on 2026-09-17. `data/archive_manifest.json` records the original workspace-relative
path, exact bytes, SHA-256 and storage location of each preserved file.

NeuroPAL activity inputs, Cook structural/chemical/gap references, Randi functional
reference matrices and published SBTG matrices are retained with the source metadata,
reference snapshots and bibliographies already present in the archived study.
See `archive/fresh/replication_20260911/inputs/published_sbtg/reference_snapshot/`
and the archived SBTG README and reports for source provenance. Calcium inputs are
MAT `norm_traces`, not camera-level raw fluorescence. Left/right and designated
other variants are combined into neuron classes by the original preprocessing.

This repository does not claim ownership of third-party data or relicense it.
Existing license files and citations are preserved. New publication scripts and
notebook are supplied as part of this research archive; no repository-wide license
was inferred from the act of public publication. Consult individual source terms
before redistribution or reuse beyond those terms.

Caches, virtual environments, Git internals and transient locks are excluded.
No original source/results are silently overwritten or repaired. New analyses are
separately versioned and explicitly distinguish historical reported values from
values recomputed from available arrays.
